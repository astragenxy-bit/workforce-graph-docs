Kiến trúc Talent Flow bằng hình

Cập nhật 23/11/2026; ghi chú thay đổi tới 26/11/2026 ở đầu tài liệu 01 và 02 (nhiều workspace, lớp thiết kế tổ chức, giao diện một luồng bốn bước). Ba tài liệu kiến trúc và hình cho SRS được viết theo nguyên tắc hình trước, chữ ngắn sau, mỗi hình có tiêu đề, một dòng cách đọc và dòng nguồn ghi file thật. Khi tài liệu và code khác nhau, code là nguồn đúng; các điểm lệch ghi ở mục cuối mỗi tài liệu.

Bốn kiểu thể hiện

Theo bốn mẫu chủ dự án chọn; mỗi hình dùng kiểu hợp nhất với nội dung, có thể phối hợp.

KiểuHợp vớiVí dụ
1. Bản đồ quy trình có mốc — nhãn mốc nền đen, biểu tượng nét đơn, mũi tên nhiều nhánh, hộp trích dẫnLộ trình, nhịp chạy, vòng đời, quyết định theo thời giangp-trien-khai, gp-quyet-dinh, kt-tac-vu-nen, dl-lich-su, srs-lo-trinh
2. Luồng công việc — hộp tối có ô kiểm, tam giác quyết định CÓ / KHÔNG, đường cam, vòng mốc thời gianLuồng có điều kiện, cổng chặnkt-request, kt-ai, dl-quy-trinh-nhap, dl-do-tin-cay, srs-tuyen-noi-bo, srs-idp, gp-nguyen-tac
3. Hệ sinh thái đồng tâm — vùng tròn lồng nhau, vòng vệ tinh, khối chữ trong vùngBối cảnh, bên liên quan, lớp và ranh giớigp-boi-canh, gp-khoi-giai-phap, kt-ngan-xep, kt-bao-mat, dl-mo-hinh-7-lop, dl-kho-postgres, srs-boi-canh, srs-quy-tac
4. Hành trình nhiều làn — làn nghiêng, nút tròn / thoi đánh số, nét đứt cam chuyển giao, vòng kết quảVai trò, tầng hệ thống, dòng dữ liệugp-gia-tri-vai-tro, kt-thanh-phan, kt-i18n, dl-dong-du-lieu, srs-use-case, a3-* (ô luồng việc)

Quy ước chung: ◆ / thoi / tam giác = bước có người quyết định; nét đứt = chưa có hoặc giả định chưa xác nhận; màu chỉ để nhấn, ý nghĩa luôn có chữ.

Vẽ lại hình

Bộ vẽ dùng chung: tools/diagrams/kit.py (không cần thư viện ngoài). Mỗi tài liệu có script riêng trong tools/diagrams/specs/ — sửa chữ hoặc bước trong script, không sửa tay SVG:

python tools/diagrams/specs/giai_phap.py
python tools/diagrams/specs/ky_thuat.py
python tools/diagrams/specs/du_lieu.py
python tools/diagrams/specs/ontology.py
python tools/diagrams/specs/srs.py
python tools/diagrams/specs/a3_huong_dan.py docs/toho-gas/img
node tools/diagrams/render_svg.mjs docs/kien-truc/img docs/kien-truc/img/gp-*.svg

render_svg.mjs xuất PNG cỡ gấp đôi và báo chữ chồng, chữ tràn, nét chạy qua chữ; đặt JPG=1 SCALE=1.25 Q=80 để ra ảnh nhẹ cho hướng dẫn sử dụng (docs/huong-dan/img-huong-dan-20-11/).
